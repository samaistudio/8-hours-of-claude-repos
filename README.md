# 8 hours of Claude repo videos, in one page

I made Claude go through the **30 most-viewed YouTube videos** about GitHub repos for Claude and Claude Code: **7 h 54 min** of video. It pulled out every repo they mention and checked each one on GitHub. This is all of it, with **who suggested each repo**, so you don't have to watch 8 hours.

Stars as of 6 Nov 2026. Everything here is free and open source. **Read a repo before you install it.**

> **Hand this to Claude:** paste this README (or point Claude Code at this repo) and say *"look at what I'm building and set me up with the 3 that help most"*.

Made by [@keepupsam](https://www.instagram.com/keepupsam/), an Information Systems student learning AI in public.
